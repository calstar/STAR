# Hotbench dry run, 2026-10-17

Branch `feedtwin/investor-polish` at `00637119`, with the user's uncommitted data in the
tree. The dry runs used the demo stack that `scripts/demo.sh` brings up: EngineDesign UI 5273
and API 8100, P&ID Designer UI 5274 and API 8101, Feed Twin UI 5277 and API 8103. That stack
runs over a curated copy of the team's data. One extra scenario used its own empty-library
stack on 8203/5377, and another used a scratch stack on 8193/5393. The browser was headless
Chromium (Playwright) at 1920x1080, with 1440x900 for the layout checks.

No repo code was changed. Nothing touched the team's library, any `.userdata/` file, or the
dev servers on 8000/8001/8003/5173/5174/5177. The quality gates that ran before the dry run
are in `baseline-2026-10-17.md`. `demo-runbook.md` is the click path being rehearsed.

**Units.** Every pressure here is psia. The Feed Twin and some EngineDesign screens show
psig; those values were converted with psia = psig + 14.696. A difference (a sag or a droop)
is in psi.

**Paths.** `$HB` means `/Users/carlton/Downloads/STAR_ASF/hotbench-investor`, where all
screenshots, raw data and logs live. Screenshots are in `$HB/shots/before/` (451 files),
so an evidence entry like `shots/before/x.png` means `$HB/shots/before/x.png`. Repo paths
are relative to the repo root. Nothing in this document is stored in the repo except the

## What worked

- **The runbook path works end to end in all three apps.** pid-designer opens on LE4 Stand
  (featured). EngineDesign Forward Mode evaluates in 0.85 s. Layer X burns LE4 (6) on helium
  in 36.6 s. The Feed Twin goes Library to LE4 (6) to Helium to T-0 to FIRE to burnout to
  Engine to Runs. The rehearsed numbers in `demo-runbook.md` reproduced exactly.
- **Repeatable and deterministic.** Eight helium cockpit burns tonight agree on mean thrust to
  6,249.1–6,250.0 N. Impulse ranges 23,618–23,729 N·s, depending on how long the stand sat at
  Ready (the LOX tank sags during the hold). Three Study runs of 10 cases were bit-identical.
- **Cross-checks hold.** The cockpit and the Study agree on mean thrust to 0.03 %. Layer X
  and the cockpit agree to 0.01 % on thrust and Pc in the parity test. Importing the stand
  and engine through the UI into an empty library reproduces the curated demo's burns to
  0.01 % on thrust, on both gases. Hand checks of Isp, c*, Cf, COPV fill mass (CoolProp),
  lockup and O/F all pass.
- **Handoffs are fast.** Building an engine card takes 3.36 s cold (worst fit error
  0.074 %) and 1.6–2.1 s cached. A drawing pull takes 29–49 ms. Re-import says "identical
  bytes". The freshness API is right both ways, and "Pull the current design" works (3.15 s).
- **Safety features on the happy path work.** The MAWP trip overlay and Reset, the Runs
  compare, and Explain (it attributes −516 N to the pressurant in 35 s) all work. So do the
  Solver PASS row, the Checks, and Configuration edit/revert.
- **Stage-worthy screens** (EYES ranking):
  1. Layer X Overview (hero row, limits, design vs feed)
  2. Feed Twin FIRE on the 10 s history window
  3. Forward Mode results with the 0.38 % CEA check
  4. Feed Twin Engine "Mixture ratio" (1.43 x 1.06 = 1.52)
  5. Layer X Hardware, Flight and Record
  6. Chamber Geometry injector views
  7. pid-designer GSE page and its light-mode export
- **Safe to run.** The empty-library backend logged 0 responses of 500 or above and no
  tracebacks. The demo data is isolated. `--reset` restores it.

### Before quoting a number

- Every burn ran on commit `00637119` with a dirty tree, and the app reports itself
  "not validated" (D-83).
- The cockpit (6,249 N) and Layer X (6,779 N) differ because they start from different T-0
  conditions, not because the solvers disagree (D-20). At the same T-0 they agree to 0.01 %.
- The helium advantage over GN2 rests on an assumed regulator droop. The team's September
  water flows measured far more sag (D-22). Do not put a He-vs-GN2 figure on a slide
  without that caveat.
- The design is named 7200N, the library engine 6800N and the config target 6,500 N, while
  the stand makes 6.25–6.78 kN (D-21).
- Layer X's rail exit, 22.1 m/s, is below the FAR-OUT 85 ft/s rule, and no limit flags it
  (D-59).
