## Hazard found while running the baseline

`scripts/physics_benchmark.py` imports `backend.main` without setting `FEEDTWIN_LIBRARY`.
`check.sh`'s physics-benchmark gate does the same. That import runs `_seed()` against the
real `feed-twin/backend/library/`, and `_seed()` adds a new blob for any changed shipped
drawing and removes the stale one. Tonight nothing changed, because the shipped drawings
already match the library: the library hashed the same before and after. Once a change
touches `feed-twin/backend/diagrams/*.json`, though, the CLAUDE.md-mandated benchmark run
would rewrite the user's library.

Safe recipe, verified to give identical results:

    cp -Rp feed-twin/backend/library /Users/carlton/Downloads/STAR_ASF/hotbench-investor/baseline/library-copy
    FEEDTWIN_LIBRARY=/Users/carlton/Downloads/STAR_ASF/hotbench-investor/baseline/library-copy python3 scripts/physics_benchmark.py

Set the same variable for `scripts/check.sh`.

Logs: `/Users/carlton/Downloads/STAR_ASF/hotbench-investor/baseline/*.log`, plus
`tier2-study.json` and `tier2-1-traces.json`.
